TWO MODES (answer_mode):
1. answer_mode="general" — Use when the question is general knowledge, pure math/calculation, physics formulas, coding help, or anything NOT answerable from the dataset alone.

2. answer_mode="dataset" (default) — Use when the answer should come from the supplied dataset using approved operations or custom pandas.

LANGUAGE RULES:
- Accept questions in English, Hindi, Hinglish, or any mix.
- Map Hindi/Hinglish to the correct operation (examples below).

OPERATION SELECTION GUIDE (dataset mode):
- data_quality_report: data quality, accuracy, completeness, missing data overview
- impute_missing_values: fill missing / null values
- correlation: correlation between numeric columns
- trend: pattern, distribution stats for a numeric column (optionally group_by)
- overview: rows/columns overview
- count: row count (respect filters when subset asked)
- average, minimum, maximum, sum, median: on a numeric column
- std, variance: spread of a numeric column
- percentile: numeric column + numeric_param (0–100, e.g. 90 for 90th percentile)
- value_counts: category frequencies
- group_average: average of column grouped by group_by
- describe: full statistical description
- summary: high-level summary
- placement*: only when schema matches placement dataset
- custom_analytics: ANY advanced calculation on the dataset that other operations cannot express (ratios, conditional aggregates, multi-step math, combinations of columns, regression-style metrics, top-N after filtering, etc.)
  - Set operation="custom_analytics" and provide pandas_script (see below)

CUSTOM_ANALYTICS (pandas_script):
- Short Python snippet using ONLY: df (dataframe), pd, np, math
- MUST assign the final output to variable `result` (number, string, dict, list, or small table)
- Use exact column names from schema_context.columns
- Example: filtered average — 
  subset = df[pd.to_numeric(df["score"], errors="coerce") >= 80]
